# OTAI Desk logo assets

Vector logos for **OTAI Desk** (portal + ticket mark, OTAI blue–purple gradient).

| File | Use |
| --- | --- |
| `otai-desk-mark.svg` | App icon, favicon source, avatars (64×64 viewBox) |
| `otai-desk-logo.svg` | Header / light backgrounds (horizontal lockup) |
| `otai-desk-logo-on-dark.svg` | Header / dark UI (e.g. Desk agent shell) |

**Meaning:** Rounded portal frame + ticket card with two lines — one portal for customers and agents, tickets synced with the existing helpdesk.

**Colors:** Gradient `#4EBFFE` → `#B83AFE` (Open Ticket AI family). UI primary purple (`#a60df2` via `otai-vue-ui`) stays for buttons; the logo aligns with OTAI vendor branding.

Copy into `otai-desk-website/public/` or `otai-desk/ui/public/` when wiring the UI.
