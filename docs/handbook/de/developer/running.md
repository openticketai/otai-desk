# Betrieb

Diese Variablen liest die App beim Start. Eine fehlende Pflichtvariable bricht den Start ab.

- `DATABASE_URL`
- `OTAI_DESK_SECRET_KEY`
- `OTAI_DESK_API_TOKEN`
- `OTAI_DESK_TICKET_PROVIDER`
- `OTAI_DESK_SEED_DEMO`
- `OTAI_DESK_DEMO_PASSWORD`

Quelle: `src/OtaiDeskApp.cs`.
