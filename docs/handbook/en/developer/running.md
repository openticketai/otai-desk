# Running

The app reads these variables at startup. A missing required variable stops the process.

- `DATABASE_URL`
- `OTAI_DESK_SECRET_KEY`
- `OTAI_DESK_API_TOKEN`
- `OTAI_DESK_TICKET_PROVIDER`
- `OTAI_DESK_SEED_DEMO`
- `OTAI_DESK_DEMO_PASSWORD`

Source: `src/OtaiDeskApp.cs`.
